# TravelLog — дневник путешествий

Мобильное приложение для Android

## Функциональность

- Ведение дневника путешествий: записи с фото, описанием, датой и геолокацией
- Список поездок с группировкой записей
- Поиск, фильтрация и сортировка записей
- Теги для записей
- Экран статистики с графиками на основе реальных данных
- Настройки: тема оформления, сортировка по умолчанию, формат даты
- Экспорт и импорт дневника в ZIP вместе с фотографиями и настройками
- Изюминка проекта: карта с отметками

## Статус разработки

Проект в активной разработке. Актуальный прогресс можно отследить в коммитах репозитория.

## Резервная копия и перенос

В настройках откройте «Резервная копия» → «Экспортировать ZIP» и выберите место сохранения
через системное окно Android. Архив содержит записи, поездки, теги, фотографии, обложки и настройки.
Для переноса скопируйте ZIP на другое устройство с TravelLog и выберите «Импортировать ZIP».

Сначала приложение проверит архив и покажет количество записей, поездок и фотографий.
После подтверждения текущий дневник и настройки будут **заменены**, без объединения записей.
Перед восстановлением сохраните текущий дневник отдельным экспортом, если он нужен.

Формат архива: версия 1, `data.json` и файлы `photos/*.jpg`. Поддерживается до 1 ГБ распакованных
данных, до 64 МБ на фотографию и до 16 МБ JSON. Неполный или повреждённый архив отклоняется
до замены дневника. Изменения таблиц Room выполняются одной транзакцией; настройки DataStore
сохраняются отдельно. Если настройки записать не удалось, приложение сообщит об этом.
Неиспользуемые фотографии очищаются автоматически при запуске и после изменения записей,
поездок или импорта. Фото, которые используются в записях или обложках поездок, сохраняются.
В настройках есть ручная очистка с количеством удалённых файлов и освобождённым местом.

## Форма и настройки

Периоды поездок не могут пересекаться: начальный и последний день включаются целиком,
по местному календарю устройства. Поездка без даты окончания занимает период от начала и далее.
При изменении дат поездки все её записи должны остаться в новом периоде.

В форме записи доступны «Без поездки» и «Автоопределение» (по умолчанию для новой записи).
Автоопределение подбирает поездку по дате и показывает её название до сохранения. Если поездки
на эту дату нет, запись сохраняется отдельно. При изменении даты записи поездка определяется заново.
Режим «Без поездки» оставляет запись отдельной даже при совпадении дат с поездкой.
Проверки повторяются в транзакции БД, чтобы одновременные операции не обходили ограничения.

Импорт также отклоняет пересекающиеся поездки и записи вне их периодов. Старые данные можно
экспортировать, но перед восстановлением архива такие конфликты нужно исправить на исходном устройстве.

Черновик записи сохраняется при пересоздании экрана системой; при выходе без сохранения
приложение запрашивает подтверждение. Для очень больших черновиков (JSON больше 128 КБ)
показывается просьба сохранить запись: они не помещаются в сохранённое состояние Android.
Доступ к выбранным фото сохраняется, если это разрешает
источник. Поиск места показывает ожидание и ошибки, место можно убрать. Повторное добавление
тега с тем же именем (без учёта регистра и крайних пробелов) выбирает существующий тег.

Настройки показывают загрузку и ошибки чтения/сохранения. При ошибке сохранения никнейма
диалог остаётся открытым. Изменение сортировки по умолчанию применяется к открытой ленте.

## Карта

Карта работает через MapLibre Native и OpenFreeMap на данных OpenStreetMap.
Регистрация, API-ключ и подключение оплаты не нужны. Для загрузки карты требуется интернет;
сами записи сохраняются локально в Room.

Источники: [OpenFreeMap](https://openfreemap.org/), [OpenMapTiles](https://openmaptiles.org/),
[OpenStreetMap](https://www.openstreetmap.org/copyright).
