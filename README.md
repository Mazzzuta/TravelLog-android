# TravelLog

TravelLog - личный дневник путешествий для Android. В нём можно сохранять заметки с фотографиями, отмечать места на карте и объединять записи в поездки.

## Возможности

- Создавать записи с датой, описанием, фотографиями, местоположением и тегами.
- Объединять записи в поездки или оставлять их отдельно.
- Искать записи по названию и тексту описания, использовать фильтры и сортировку для записей.
- Оставлять метки на карте и переходить от отметки к записи.
- Смотреть статистику: записи по месяцам, количество поездок, фотографий и мест, а также частые теги.
- Настраивать оформление с помощью встроенных цветовых схем.

## Карта

Карта работает на MapLibre Native. Картографические данные предоставляет OpenFreeMap на основе OpenStreetMap. Чтобы отметить место, можно ввести подробный адрес или название места либо использовать геопозицию телефона.

Интернет нужен для загрузки карты и поиска мест по адресу или названию. Записи можно читать и редактировать без сети.

## Хранение данных

Записи, поездки, теги и координаты хранятся в локальной базе Room. Приложение хранит копии прикреплённых фотографий в своём хранилище, а настройки - в DataStore. Регистрация не нужна, облачной синхронизации нет.

В настройках можно экспортировать дневник с фотографиями и настройками в ZIP и перенести его на другой телефон. Импорт заменяет текущий дневник.
